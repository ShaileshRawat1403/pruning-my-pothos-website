# Playbook: Content Cluster Rollout (SEO/AEO/GEO)

## Objective
Ship a coherent topic cluster that improves search visibility and answer/citation coverage without reducing editorial quality.

## Steps
1. Select one core topic entity and define user intents.
2. Pick one flagship page (deep), 2-4 supporting pages (specific intents), and cross-section supports.
3. Define canonical internal link map before drafting.
4. Draft or update pages with clear section intent and answerable summaries.
5. Add or refine metadata and schema to match visible content.
6. Validate links, structure, and consistency checks.
7. Publish and track metrics in a defined observation window.

## Acceptance criteria
- Flagship page exists and is internally linked by all support pages.
- Supporting pages each target a distinct sub-intent.
- No duplicate/slightly-rephrased pages in the same cluster.
- Metadata and heading structure align with user intent.
- Baseline consistency checks pass.

## Failure modes
- Topic overlap with no clear page differentiation.
- Missing reciprocal links from supports to flagship.
- Overly broad pages trying to satisfy all intents.
- Schema added without visible supporting content.
