# Playbook: Distribution and Canonical Syndication

## Objective
Increase off-site citation signals without splitting authority from the primary site.

## Approach
1. Select one flagship explainer per cluster.
2. Publish an adapted summary externally (community/newsletter/platform).
3. Add canonical reference back to the original site URL whenever platform supports it.
4. Add one explicit in-body source line linking to the canonical original.
5. Track referral and citation deltas after publication.

## Rules
- Never publish full duplicate content without canonical attribution.
- Keep external versions shorter and context-adapted.
- Preserve consistent entity names between original and cross-post.

## Minimum metadata for each cross-post log
- Date
- Target platform
- Canonical URL used
- Topic cluster
- Observed outcomes after 14 and 30 days

## Success signal
External references increase while canonical pages maintain ranking and citation coherence.
