# Playbook: Measurement and Reporting (SEO/AEO/GEO)

## Objective
Measure optimization impact using repeatable checks rather than one-off anecdotes.

## Baseline before changes
- Capture current page list, titles, descriptions, and index status snapshot.
- Record priority query set and expected answer/citation targets.
- Save current internal-link map for affected pages.

## Reporting windows
- T+7 days: technical and crawl sanity.
- T+14 days: early ranking/click and answer-surface signal.
- T+30 days: stable trend assessment.

## Core metrics
- SEO: indexed coverage, impressions, clicks, CTR, crawl errors.
- AEO: answer inclusion rate for selected prompt/question set.
- GEO: citation/mention presence and retrieval fidelity in test prompts.

## Report format
- What changed
- What improved
- What regressed
- Hypothesis for each movement
- Next experiment

## Guardrail
Do not claim causal success without before/after comparison and a stable window.
