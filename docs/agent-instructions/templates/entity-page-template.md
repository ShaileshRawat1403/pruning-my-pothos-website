# Template: Entity-Centric Page

## Goal
Create a page that is easy for users and machines to identify as the canonical explanation of one entity.

## Structure
1. Entity definition (one paragraph, plain language).
2. Why it matters (context + use cases).
3. How it works (model/mechanism).
4. Common misconceptions.
5. Failure modes and boundaries.
6. Related entities (internal links).
7. Sources/references if factual claims need attribution.

## Rules
- Keep one dominant entity focus.
- Avoid mixing multiple primary entities without explicit comparison framing.
- Keep terminology stable across title, headings, and body.
