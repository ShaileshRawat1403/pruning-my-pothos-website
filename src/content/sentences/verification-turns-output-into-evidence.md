Language can report success even when nothing useful changed. That behavior is normal in generative systems.

Verification is what converts output into evidence. A passed check, an observed file diff, or a confirmed artifact carries more meaning than fluent text.

Reliability grows when systems reward proof instead of confidence.

**What this changes in practice:** treat every completion as provisional until a verifiable signal confirms it.
